## 💻 Sobre o projeto

<!-- EXPLICA O MOTIVO DO PROJETO -->
Fintech é um projeto desenvolvido durante o curso de Desenvolvedor Front-End com o objetivo de praticar e consolidar os fundamentos do HTML e CSS.Durante o desenvolvimento, foram aplicados conceitos importantes de estruturação semântica, organização de código, boas práticas de acessibilidade, estilização com CSS e criação de layouts responsivos.
